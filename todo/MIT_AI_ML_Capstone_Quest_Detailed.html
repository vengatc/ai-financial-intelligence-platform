Week 1 – Data Engineering Kingdom

Project Setup

  • ☑ Create GitHub repository
  • ☑ Create Python virtual environment
  • ☑ Install pandas, yfinance, transformers, scikit-learn, streamlit, plotly, optuna, shap
  • ☑ Create folders: data/raw, data/processed, notebooks, src, app, models, reports
  • Deliverable: Project skeleton committed to GitHub

Collect Stock Data

  • ☑ Choose stocks: AAPL, MSFT, NVDA, AMZN, META, GOOGL, TSLA
  • ☑ Download 3-5 years of daily OHLCV data with yfinance
  • ☑ Save one CSV per stock under data/raw/prices

Collect News

  • ☑ Download FNSPID or FiQA
  • ☑ Filter news for chosen tickers
  • ☑ Inspect missing values and duplicates

Merge Data

  • ☑ Group headlines by ticker/date
  • ☑ Merge with stock prices
  • ☑ Create NextDayUp target
  • ☑ Save master_dataset.csv (saved as all_training_dataset.csv + per-ticker <TICKER>_training_dataset.csv)

Feature Engineering

  • ☑ Calculate SMA(10,20)
  • ☑ EMA

  • ☑ Daily Return
  • ☑ Volatility
  • ☑ Verify no missing values
Week 2 – Transformer Intelligence

FinBERT

  • ☑ Load HuggingFace FinBERT
  • ☑ Test on sample headline

Sentiment

  • ☑ Score every headline (positive/neutral/negative)
  • ☑ Store probabilities

Aggregate

  • ☑ Compute daily average sentiment (data/processed/daily/<TICKER>_daily_sentiment.csv)
  • ☑ Apply weighted decay (SentimentEMA = AvgSentiment.ewm(span=5) per ticker)
  • ☑ Save master_dataset_with_sentiment.csv (saved as all_training_dataset.csv + per-ticker <TICKER>_training_dataset.csv)

Visualise

  • ☑ Plot price vs sentiment (notebooks/06_Visualization.ipynb)
  • ☑ Write observations (Observations section in 06_Visualization.ipynb)
